## Очистка шума в данных с помощью нейронной сети (любую архитектуру на выбор)

#### Входные данные (файлы вида tensor_datasetN.pt):  
У вас есть несколько файлов данных (tensor_dataset.pt, tensor_dataset1.pt, ..., tensor_dataset5.pt). Каждый файл содержит:  
    Детекции (X) - исходные данные с шумом (входные данные для сети)  
    "Модель" (Y) - предполагаемые правильные данные (целевые данные для сети)  

Несоответствие значений детекции значениям модели является шумом. Каждый файл представляет собой отдельный, независимый набор данных (например, отдельный лог или сессию).

#### Задача:
    1) обучить нейронную сеть, которая будет очищать шум из детекций, преобразуя их максимально близко к данным "модели". Сеть должна обучаться на данных из всех предоставленных файлов.
    2) сделать единый тренировочный, валидационный и тестовый сет из всех данных в соотношении (70/20/10) соответственно. (Важно: не делить каждый файл отдельно, а объединить данные перед разделением, либо обеспечить стратификацию по файлам, если это имеет смысл).
    3) оформить на гитхабе следующее (все графические результаты в виде графиков):
        3.1) результаты обучения (график функции потерь на тренировочном и валидационном наборах по эпохам),
        3.2) показать на нескольких сэмплах из тестового набора результат работы модели (например, графики: исходный шумный сигнал, сигнал "модели", очищенный сигнал),
        3.3) посчитать метрики (precision, recall, F1-score) для тестового набора и представить результаты (можно в виде таблицы или графика).


#### Временная зависимость данных:
Данные внутри каждого отдельного файла (.pt) отсортированы по времени в хронологическом порядке и имеют временную зависимость (т.е. значение в момент t зависит от значений в моменты t-1, t-2 и т.д.).

Однако, разные файлы (tensor_dataset.pt, tensor_dataset1.pt и т.д.) являются независимыми друг от друга (представляют отдельные логи/сессии). Временная последовательность между файлами прерывается. Учитывайте это при объединении (если обьединение необходимо) данных и формировании выборок или батчей, чтобы не создавать ложных зависимостей между данными из разных файлов.

#### Важные моменты:
Данные "модели" (Y) могут содержать ошибки и не всегда быть идеально точными.

#### Данные записаны в следующем формате (внутри каждого .pt файла):

>     torch.save({
>         'X': X_tensor,
>         'y': y_tensor
>     }, save_path)
